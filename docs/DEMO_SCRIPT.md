# DeckFit AI — ForgeHacks Demo Script — target 2:40–3:10

DeckFit AI is the public ForgeHacks name. The deployed interface may display the historical internal name Venue Agent.

## 0:00–0:15 — Hook

Show the project-owned slide.

“This presentation looks fine on my laptop. But the audience is not sitting at my laptop. The same media is being projected into a real room.”

## 0:15–0:35 — Product thesis

“Presentation software understands the slide. Venue guidance understands the room. DeckFit AI connects the two — a bounded first step toward responsive presentation design for physical spaces.”

## 0:35–1:05 — Deterministic analysis

Load **Try demo venue** and run analysis.

“The AI does not calculate geometry. Deterministic code establishes supported facts against a named reference profile. Estimated measurements near a decision boundary are review-only.”

Do not say the system proves human readability.

## 1:05–1:35 — Bounded AI planning

Show candidate tradeoffs and run planning.

“The model can return only IDs from candidates the server already generated and simulated. It cannot invent a font size, rewrite copy, mutate titles, or mark its own work verified.”

Show planner provenance. If fallback is used, say so rather than implying Gemini ran.

## 1:35–1:55 — Exact human approval

Show the exact plan and combined simulation, then approve.

“Approval is bound to this source, ordered candidate set, constraints, and simulation evidence. Replanning invalidates the approval.”

## 1:55–2:25 — Saved-artifact verification

Show the output being written, reopened, rerendered, and reanalyzed.

“The planner recommends. The verifier decides.”

If the result is `VERIFIED`, immediately clarify: “That means the supported structural postconditions passed — not that every individual can read the slide or that the deck is accessibility/AVIXA certified.”

## 2:25–2:45 — Responsible refusal

Briefly show an unsupported visual/opaque-overlay fixture or mention it.

“Unknown never becomes pass. Unsupported visible content remains review-only instead of disappearing from coverage.”

## 2:45–3:00 — Close

“Responsive design adapted media to screens. DeckFit AI explores the same idea for physical presentation spaces — with bounded AI, explicit approval, and artifact-level verification.”
